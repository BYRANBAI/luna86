## 🐛 Troubleshooting

### Проблема: "Туннель недоступен"
**Решение:** Перезапустите localtunnel
```bash
# Остановите старый процесс (Ctrl+C)
lt --port 3000 --subdomain luna-cafe-demo
```

### Проблема: "CRM зависает на проверке доступа"
**Решение:** Уже исправлено в текущей версии. Если повторяется:
1. Очистите cookies браузера для localhost:3000
2. Перезапустите сервер: `npm run dev`

### Проблема: "Профиль не загружается"
**Решение:** Убедитесь, что вы вошли через `/auth` с паролем `demo123`

### Проблема: "Меню пустое"
**Решение:** Перезаполните базу данных
```bash
npm run db:seed
```
