## 📌 Что это за проект?

**Luna Sushi Bar** — полноценная система управления суши-баром с:
- Меню для гостей (43 ролла)
- POS-терминал для кассиров
- CRM для управляющего
- Кухонный экран (KDS)
- Киоск самообслуживания

**Технологии:** Next.js 16, React 19, TypeScript, Prisma, SQLite (dev), WebSocket

## 🎓 Контекст для понимания

### Почему gradient placeholder'ы?
Заказчик не предоставил фото. Вместо серых квадратов сделаны красивые цветные градиенты (10 цветов, уникальный для каждого ролла по названию).

### Почему исправляли авторизацию?
API `/api/admin/login` использовал неправильные имена cookies (`refreshToken` вместо `luna_refresh_token`). Заменено на функцию `setAuthCookies()` из `lib/auth.ts`.

### Почему добавляли пароли гостям?
В seed.ts не было `passwordHash` для гостей. Профиль требовал авторизации, но войти было нельзя. Добавлен пароль `demo123` для всех.

### Почему заменили меню?
Было старое меню кафе (кофе, завтраки). Заказчик хочет суши-бар. Заменено на 43 ролла в 6 категориях.
