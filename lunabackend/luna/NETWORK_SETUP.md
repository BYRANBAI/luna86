# Настройка сетевой архитектуры Луна POS

## 🌐 Сетевая архитектура

### Топология сети:
```
┌─────────────────────────────────────────────────────┐
│              Серверный блок (Main Server)           │
│  - Windows 10/11 Pro или Windows Server             │
│  - IP: 192.168.1.100 (пример)                     │
│  - Next.js сервер на порту 3000                    │
│  - SQLite база данных                             │
│  - Централизованное хранилище данных               │
└─────────────────────────────────────────────────────┘
                          │
                          │ Локальная сеть (LAN)
                          │
          ┌───────────────┼───────────────┐
          │               │               │
┌─────────┴─────┐ ┌──────┴──────┐ ┌─────┴──────┐
│   Планшет     │ │  Компьютер   │ │   Кухня    │
│   официанта   │ │ администратора│   (KDS)     │
│  - IP DHCP    │ │  - IP DHCP   │ │  - IP DHCP  │
│  - Port 3000  │ │  - Port 3000  │ │  - Port 3000│
└───────────────┘ └──────────────┘ └─────────────┘
```

## 🔧 Настройка сервера

### 1. Настройка статического IP (рекомендуется):
```powershell
# На сервере задайте статический IP
# Пример: 192.168.1.100
# Маска: 255.255.255.0
# Шлюз: 192.168.1.1
```

### 2. Настройка Next.js для сетевого доступа:
В `next.config.ts` уже настроено:
- `output: 'standalone'` - для production
- `allowedDevOrigins` - для разработки

### 3. Запуск сервера в production режиме:
```bash
cd luna
npm run build
npm run start
```

Сервер будет доступен по адресу: `http://192.168.1.100:3000`

## 🔒 Настройка безопасности сети

### 1. Настройка Firewall на сервере:
```powershell
# Разрешить входящие подключения на порт 3000
New-NetFirewallRule -DisplayName "Luna POS Server" -Direction Inbound -LocalPort 3000 -Protocol TCP -Action Allow
```

### 2. Настройка локальной сети:
- Все устройства должны быть в одной подсети
- Рекомендуется использовать отдельный VLAN для POS системы
- Ограничить доступ из интернета

### 3. Безопасность приложения:
- Ролевая система доступа уже настроена
- Пароли по умолчанию: luna123
- Рекомендуется сменить пароли после первой установки

## 📡 Настройка синхронизации

### Polling конфигурация:
- Клиенты опрашивают сервер каждые 2.5 секунды
- Автоматическое обновление данных
- Синхронизация статусов заказов

### WebSocket (планируется):
- Реальное время обновлений
- Меньшая нагрузка на сеть
- Более быстрая синхронизация

## 🚀 Установка на клиентских устройствах

### Script для автоматической установки:

#### Планшет официанта:
```powershell
# Скачивание приложения
Invoke-WebRequest -Uri "http://192.168.1.100:3000/downloads/luna-pos-waiter.exe" -OutFile "luna-pos-waiter.exe"
# Установка
Start-Process "luna-pos-waiter.exe" -ArgumentList "/S"
```

#### Компьютер администратора:
```powershell
# Скачивание приложения
Invoke-WebRequest -Uri "http://192.168.1.100:3000/downloads/luna-pos-admin.exe" -OutFile "luna-pos-admin.exe"
# Установка
Start-Process "luna-pos-admin.exe" -ArgumentList "/S"
```

## 🔧 Troubleshooting

### Проблема: Устройства не видят сервер

**Решения:**
1. Проверьте подключение к локальной сети
2. Проверьте Firewall на сервере
3. Убедитесь, что сервер запущен: `http://192.168.1.100:3000`
4. Проверьте пинг до сервера: `ping 192.168.1.100`

### Проблема: Медленная синхронизация

**Решения:**
1. Проверьте загрузку сети
2. Уменьшите количество устройств
3. Оптимизируйте базу данных
4. Рассмотрите WebSocket вместо polling

### Проблема: Потеря данных при отключении сети

**Решения:**
1. Включите автономный режим (планируется)
2. Добавьте локальное кэширование
3. Реализуйте очередь изменений
