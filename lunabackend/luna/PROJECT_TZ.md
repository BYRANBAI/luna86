# Луна POS - Техническое задание и документация проекта

## 📋 Общее описание

**Проект:** Луна POS - система управления кафе
**Тип:** Веб-приложение с Next.js + Prisma + SQLite + Electron
**Цель:** Создание внутренней экосистемы кафе с планшетом официанта, компьютером администратора и кухонным экраном
**Платформа:** Windows-приложение с сетевой архитектурой

## 🏗️ Архитектура системы

### Устройства в экосистеме:
1. **🖥️ Серверный блок** - центральный сервер с базой данных (Windows 10/11 Pro или Server)
2. **💻 Компьютер администратора** - полный POS с управлением (Electron приложение)
3. **📱 Планшет официанта** - мобильный POS для заказа у стола (Electron приложение)
4. **👨‍🍳 Компьютер на кухне** - KDS экран для поваров (Electron приложение)

### Технологический стек:
- **Frontend:** Next.js 16.3.0 + React 19 + TypeScript
- **Backend:** Next.js API routes
- **Desktop:** Electron 43.3.0 + Electron Builder
- **Database:** Prisma ORM + SQLite
- **Styling:** Tailwind CSS 4
- **Real-time:** Polling каждые 2.5 секунды
- **Network:** Локальная сеть (LAN)

## 🎯 Ключевые функции POS

### Вкладки POS:

#### 🪑 Столики
- Схема зала с 8 столиками
- Детальная информация о каждом столике:
  - Статус (свободен/занят/готов)
  - Сумма текущего чека
  - Время пребывания гостей
  - Количество гостей
- Управление заказами:
  - Добавление позиций в заказ
  - Изменение количества (+/-)
  - Удаление позиций
  - Разделение счёта
- Категоризированное меню (кофе, завтраки и т.д.)
- Поиск блюд
- Статус готовности в реальном времени:
  - 📝 В ожидании
  - ⏱ Готовится (X мин)
  - ✓ Готов к подаче
- Управление столиком:
  - ❌ Отменить заказ (гости ушли без оплаты)
  - 🗑 Освободить столик (нормальное завершение)
  - ✕ Закрыть (сохранить текущий заказ)

#### 📅 Брони
- Список всех броней с деталями
- Создание новой брони
- Подтверждение/отмена броней
- Цветовая индикация статуса

#### 📋 Заказы
- Лента всех заказов
- Фильтрация по источнику (Сайт/Киоск/Зал/Доставка)
- Анимированные таймеры готовки с прогресс-баром
- Детальная информация о заказах
- Печать чека

#### 🚶 Очередь
- Управление электронной очередью
- Добавление в очередь
- Отметка "Готово"
- Удаление из очереди

### Дополнительные функции:

#### Поиск и управление гостями:
- Поиск по номеру телефона
- Поиск по имени
- Создание нового гостя через кнопку "+"
- Отображение бонусов
- Списание бонусов при оплате

#### Оплата:
- Наличные
- Карта
- QR/СБП
- Смешанная оплата (бонусы + карта)
- Разделение счёта

## 🔧 Технические детали

### Установка и запуск (Web версия):
```bash
cd luna
npm install
npm run db:push
npm run db:seed
npm run dev
```

### Установка и запуск (Electron версия):
```bash
cd luna
npm install
npm run db:push
npm run db:seed
npm run electron:dev  # Режим разработки
npm run electron:build:win  # Сборка для Windows
```

### Electron скрипты:
- `npm run electron` - запуск Electron приложения
- `npm run electron:dev` - одновременный запуск Next.js и Electron
- `npm run electron:build` - сборка Electron приложения
- `npm run electron:build:win` - сборка для Windows (NSIS + Portable)

### Конфигурация:
- **next.config.ts:** Добавлен `allowedDevOrigins: ['127.0.0.1']` для CORS
- **DATABASE_URL:** `file:./prisma/dev.db` (SQLite)
- **Порт:** 3000

### API Endpoints:
- `GET /api/state` - получение всех данных (polling)
- `POST /api/orders` - создание заказа
- `PATCH /api/orders` - обновление статуса заказа
- `GET /api/auth/login` - авторизация
- `POST /api/auth/logout` - выход

### Структура базы данных:
- **Category** - категории меню
- **Item** - блюда/напитки
- **Order** - заказы
- **OrderLine** - позиции в заказе
- **Guest** - гости/клиенты
- **User** - сотрудники с ролями
- **Reservation** - брони
- **Table** - столики (DiningTable)
- **Hall** - залы
