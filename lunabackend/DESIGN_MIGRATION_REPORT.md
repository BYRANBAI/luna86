## Вопросы и ответы

**Q: Почему красный цвет вместо золотого?**  
A: Restaurant App дизайн обычно использует красный как аппетитный акцент. Золотой (#e7bd61) можно вернуть, изменив `--accent-primary`.

**Q: Можно ли оставить тёмную тему?**  
A: Да, можно сделать toggle или использовать CSS `prefers-color-scheme`. Нужно добавить дублирующие переменные для dark mode.

**Q: Как обновить остальные страницы?**  
A: Использовать те же компоненты (`.panel`, `.btn`, `.card`) и CSS переменные. Следующий агент может продолжить с `/menu`.

**Q: Нужно ли обновлять Figma?**  
A: Если есть дизайн-макеты, стоит синхронизировать. Текущая реализация — интерпретация паттернов Restaurant App.
