# План миграции дизайна Luna → Restaurant App (Figma)

## Исходная ситуация

**Текущий дизайн Luna:**
- Тёмная тема: фон `#08111f` / `#101d30`, текст `#f7f0df`
- Золотой акцент: `#e7bd61` / `#f3cc74`
- Стиль: космическая/лунная эстетика, градиенты, панели с тенями
- Карточки: rounded-18px, borders, hover-эффекты
- Меню: 10 уникальных gradient placeholder'ов для блюд

**Целевой дизайн (Restaurant App из Figma):**
- Светлая/чистая тема с акцентом на фото блюд
- Минималистичный, современный UI
- Карточки с реальными изображениями еды
- Фокус на юзабилити и скорости заказа
- Нижняя навигация, крупные тап-зоны

## Ключевые изменения

### Цветовая палитра
```css
/* Было (Luna космическая) */
--bg: #08111f;
--panel: #101d30;
--text: #f7f0df;
--accent: #e7bd61;

/* Станет (Restaurant App) */
--bg: #FFFFFF;
--surface: #F8F9FA;
--text: #212529;
--accent: #FF6B6B; /* или другой из макета */
```

### Типографика
```css
/* Было */
font-family: Arial, Helvetica, sans-serif;

/* Станет */
font-family: 'Inter', -apple-system, sans-serif;
/* или шрифты из макета */
```

### Компоненты
- **Карточки блюд:** квадратные фото → прямоугольные 16:9
- **Кнопки:** золотые с тенями → минималистичные solid/outline
- **Навигация:** верхняя → нижняя (mobile-first)
- **Иконки:** кастомные → система иконок из макета

## Риски и ограничения

1. **Фото блюд:** сейчас gradient placeholder'ы, нужны реальные фото
2. **Шрифты:** если макет использует платные шрифты, нужна замена
3. **Иконки:** возможно нужна иконочная библиотека (Heroicons, Lucide)
4. **Брендинг:** Luna имеет космическую тематику, Restaurant App нейтральный
5. **Тёмная тема:** макет может быть только светлым
